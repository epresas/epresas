## What I'm exploring

### AI-native software engineering

I'm increasingly interested in what happens when AI becomes part of the **software engineering workflow itself**, rather than simply another coding assistant.

I'm exploring ideas around autonomous engineering workflows that can:

- Understand a task and its acceptance criteria
- Investigate issues, codebases and external context
- Use specialised agents and tools
- Build an implementation plan
- Execute and validate changes
- Run unit and E2E tests
- Manage GitHub/GitLab workflows
- Track the state of a task across its entire lifecycle
- Diagnose failures and iterate
- Select models and tools with **cost awareness**

The goal isn't simply to generate code.

It's to explore how an engineering task could become a **stateful, observable and self-correcting workflow**.

## Open Source

### ⚛️ React Hooks Collection

A reusable React hooks library extracted from patterns I repeatedly found myself implementing across projects.

The library contains **13 hooks written in strict TypeScript**, with tests and documentation focused not only on usage, but also on implementation decisions, edge cases and common React pitfalls such as stale closures, cancellation and event lifecycle management.
